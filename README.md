# College Attendance Analyzer

## Project Overview

The College Attendance Analyzer is a Python-based project developed to manage and analyze student attendance records.

## Features

- Calculates student attendance percentages.
- Identifies students below the minimum attendance requirement of 75%.
- Displays subject-wise average attendance.
- Generates bar charts and pie charts for attendance analysis.
- Validates attendance records and skips invalid data.

## Technologies Used

- Python
- Pandas
- CSV
- Matplotlib

## Project Files

- "attendance_analyzer.py" – Main Python program.
- "attendance.csv" – Attendance dataset.
- "SUMMARY.md" – Project implementation details and test cases.

## Minimum Attendance

The minimum required attendance percentage is 75%.
